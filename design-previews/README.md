# Design Previews

Bu klasör yalnızca görsel tasarım artifact'leri içindir.

Buradaki dosyalar production sayfaları değildir.

Amaç, Astro generator'a dokunmadan önce farklı tasarım yönlerini bağımsız olarak test etmektir.

Onaylanan tasarımlar daha sonra Astro component/template yapısına dönüştürülecektir.

Bu klasörde mevcut generator component'leri kullanılmaz.

Her artifact tek başına çalışan HTML dosyası olmalıdır ve CSS dosya içinde (internal CSS) bulunmalıdır.

Her artifact, tarayıcıda doğrudan açılabilir olmalıdır.

Bu aşamada yeniden kullanılabilirlikten çok görsel kalite önceliklidir.
