# Design References

Use these references as inspiration only. Do not copy exact layouts, proprietary assets, brand wording, animations, fonts, or full page structures.

# Design Reference Usage

Reference files live under `docs/reference-styles/[reference-name]/`.

Each reference may include:
- `design-compact.md`
- `design-extended.md`
- `tokens-compact.json`
- `tokens-extended.json`

Use `design-compact.md` for normal design decisions.
Use `design-extended.md` only when a deeper redesign or component-level refinement is needed.
Use token JSON files only to translate colors, spacing, and typography into our own theme system.

Do not copy a reference site directly.
Do not copy proprietary fonts, brand wording, unique illustrations, exact layouts, or animation sequences.
Translate references into reusable local-business modules.

## Archetype 1: Soft Beauty Editorial

Use for:
- Bridal hair & makeup studios
- Beauty salons
- Makeup artists
- Instagram-heavy visual businesses

Inspired by:
- GlossGenius
- Aaether
- Lacey
- Bella Kitchen

Modules:
- editorial hero
- soft service carousel
- Instagram preview grid
- sticky WhatsApp CTA
- bridal/special-day service cards
- soft background ornaments

Good for:
- Basic
- Booking

Avoid:
- SaaS-like product copy
- fake before/after visuals
- overbuilt scroll animation
