# Visual Acceptance Checklist

Reject a demo if any of the following is true:

- first screen looks generic
- hero uses card-inside-card composition
- crude placeholders are visible
- page lacks visual density
- footer is weak or incomplete
- mobile header is too tall
- services page looks the same as home page
- contact page lacks map/contact/social/about structure
- Turkish characters are broken
- WhatsApp CTA is unclear
- page feels like a basic AI template

## Acceptance Notes

- Build/check success is required but not sufficient.
- Visual acceptance must pass before outreach.
- Rejection should trigger component-level improvement, not one-off patch styling.
