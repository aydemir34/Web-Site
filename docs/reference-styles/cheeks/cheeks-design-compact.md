# Cheeks + Co — Style Reference
> Warm spa editorial. A visual system built around high-key beauty photography, terracotta warmth, and a confident "Book Now" conversion rhythm.

**Theme:** light-warm

Cheeks + Co uses a warm, approachable luxury aesthetic. Deep burgundy-terracotta accents on a cream-warm white base. Photography is central — clean, skin-forward, bright. Typography mixes a confident serif for headlines with a clean readable sans for UI. The overall feel is "clean beauty studio" rather than clinical or cold. Components have gentle rounding, warm backgrounds, and a strong conversion focus.

## Colors

| Name | Value | Role |
|------|-------|------|
| Bordeaux | `#4c292b` | Primary accent, CTA buttons, hover states, logo — anchors the warm luxury identity |
| Cream White | `#fdfaf7` | Page background, card surfaces — warmer than pure white, softer on eyes |

## Typography

### Freight Display Pro / Playfair Display substitute
- **Role:** Primary headlines, hero H1, section titles — confident, editorial serif
- **Weights:** 400, 700
- **Sizes:** 32px–60px display, 20px–28px section heading
- **Line height:** 1.10–1.20 tight for display, 1.35 for section headings

### Inter / DM Sans substitute
- **Role:** Navigation, body, buttons, captions, service descriptions
- **Weights:** 400, 500, 600
- **Sizes:** 13px–18px
- **Line height:** 1.50–1.65
- **Letter spacing:** 0.02em navigation, 0.04em uppercase labels

## Spacing & Layout

**Base unit:** 4px

**Density:** comfortable-generous — not sparse luxury but not dense either

- **Section gap:** 64px–96px
- **Card padding:** 24px–32px
- **Element gap:** 12px–16px
- **Max content width:** 1200px centered

### Border Radius

- **buttons:** 6px — slight round, not pill
- **cards:** 12px–16px
- **inputs:** 6px

## Components

### Primary CTA Button
**Role:** "Book Now" — the main conversion action

Background Bordeaux (#4c292b), white text, 6px radius, 14px–16px Inter Medium, generous padding (14px 28px). Hover: slightly lighter burgundy. Never a ghost button for primary action.

### Ghost / Outline Button
**Role:** Secondary actions like "View Menu", "Learn More"

Border 1.5px solid Deep Ink or Bordeaux, transparent background, Deep Ink text. 6px radius.

### Service Card
**Role:** Individual service presentation

Card background Warm Linen (#f3ece4), 16px radius, 24px padding. Service name in serif medium, price right-aligned, short description in small sans. No heavy border. Subtle hover shadow.

### Navigation Bar
**Role:** Primary site header

White/cream background, centered logo, right-side "Book Now" Bordeaux button always visible. Desktop: horizontal links. Mobile: hamburger → full-screen or drawer overlay. Header stays compact on mobile — never stacks.

### Section Hero
**Role:** Full-width editorial image with text overlay or split layout

High-key photography full-bleed or 60/40 split. Text side on cream background. H1 in serif. Always a Bordeaux "Book Now" CTA.

## Do's and Don'ts

### Do
- Lead every page with strong editorial photography — skin, hands, studio, soft product close-ups
- Use Bordeaux as a confident accent — not all over, but clearly visible on CTA and key moments
- Keep navigation compact on mobile — one row, hamburger, no stacking
- Use Warm Linen as section separators instead of borders or heavy cards
- Keep service descriptions short and scannable, price visible
- Add "Book Now" in multiple locations — header, hero, after service list, footer

### Don't
- Don't use pure black (#000) — use Deep Ink (#1a1008) for warmth
- Don't use pure white — use Cream White (#fdfaf7) as base
- Don't use flat clinical layouts — everything should feel spa-warm
- Don't stack phone + WhatsApp + nav in mobile header
- Don't use heavy drop shadows — prefer subtle shadows or none
- Don't use animated gradients or flashy scroll effects
- Don't use cold blues, grays, or sterile medical language

## Layout

Full-bleed hero photography → warm linen service section → trust/why strip → most-booked services grid → booking CTA. Navigation is sticky, minimal, always showing "Book Now". Section rhythm alternates cream white and warm linen backgrounds for visual breathing room.
